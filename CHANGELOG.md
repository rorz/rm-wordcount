# Changelog

## 0.1.0 — 2026-10-22

First release.

- A small word count in the corner of the current notebook page.
- Show or hide it from the notebook menu; the choice is remembered.
- Counts saved typed text, including handwriting converted to text.
- Supports reMarkable OS 3.27.3.0 and 3.28.0.172 through XOVI.
- Installable through reManager, with a recipe for Vellum.

The runtime is unchanged from alpha 4. Updates follow native autosave.
See [known limitations](docs/compatibility.md#known-limitations).
